## 输入与输出

输入：待审核正文、证据资料与来源日期；账号身份和受众。

输出：content-evidence.md：原句/主张类型/证据/结论/修订句；附修订后全文（用户要求时）。

## 工作步骤

1. 拆出可核实主张，记录原句位置；观点与事实分开。
2. 逐条判断支持、部分支持、冲突、无来源、已过时，证据必须能支持原主张的主体、范围和时间。
3. 重点核对排名、因果、客户数量、认证、价格和案例归属；截图只证明可见范围。
4. 给出保留、缩小表述、删除或补证据的建议及替换句。没有来源不等于已证伪。
5. 输出阻碍发布的具体项；修改后复核受影响段落，不能用综合分掩盖关键缺证。

## 使用方法

这是供支持 SKILL.md 的 AI 工具读取的工作流技能，不是独立网站或浏览器插件。

1. 从仓库 **Code → Download ZIP** 下载并解压，保留全部文件及目录结构。
2. 按所用 AI 工具的安装方式导入该目录；是否兼容以实际导入和运行结果为准。
3. 提供所需材料并明确调用 `seoguan-content-evidence`。支持 `$技能名` 的宿主可使用下方示例。

依赖：不要求 Python、GEO 后台账号或付费 API。需要宿主具备读取所提供材料的能力；宿主模型服务可能有费用。
